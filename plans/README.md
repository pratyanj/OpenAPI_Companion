# Implementation Plans Archive (`plans/`)

This directory serves as the permanent, version-controlled archive of all technical implementation plans created during development.

## Purpose
- **Auditability & Traceability**: Review what technical architecture, interfaces, and UI patterns were planned and implemented on any given date.
- **Context Preservation**: Understand why certain design choices were made (e.g. project isolation vs. global storage, in-page Shadow DOM overlays vs. narrow sidebar modals).
- **Future Reference**: Easily compare future feature iterations against original implementation plans.

## Naming Convention
```
plans/YYYY-MM-DD_<feature_name>.md
```
