# Implementation Plan: Release Version 1.3.1

Prepare, document, test, and package OpenAPI Companion **v1.3.1**.

## 1. Release Scope & Highlights (v1.3.1)

Version 1.3.1 delivers major productivity enhancements across Authentication, Variables, In-Page Swagger integration, and Backup automation:

1. **In-Page Swagger UI Endpoint Execution History Button**:
   - Dynamic `[History count]` button on operation summary bars when past executions exist (`count > 0`).
   - Sits neatly after the operation description and before native Swagger controls (`[clipboard]`, `[lock]`, `[v arrow]`).
   - Click opens `HistoryDetailModal` pre-filtered to the specific endpoint.
   - Configurable via `endpointHistoryButton` switch in Config panel.
2. **In-Page Swagger UI "Save Request" Action Button**:
   - 1-Click "Save Request" button in 2xx response sections pre-filling the Preset Editor modal with path, parameters, body, and description.
3. **Editable Auto-Extraction Rules & UI Polish**:
   - Auto-extraction rules in Variables tab now include an edit pencil button with pre-populated inputs.
   - Corrected icon semantics for Import (download arrow into tray) and Export (upload arrow out of tray).
4. **Auth Tab Raw JSON Persona Import**:
   - Paste raw JSON login payloads with automatic email-based persona name derivation and extra custom payload parameters.
5. **Environment Variables Raw JSON Import**:
   - Direct pasting of JSON responses/configs with recursive flattening into `{{VAR}}` interpolation keys, secret detection, and syntax validation.
6. **Firefox-Exclusive Automated Backups & 1-Minute Undo Grace Period**:
   - Clean background automated backups in Firefox without download prompts; completely hidden in Chrome for distraction-free UI.
   - Auto-dismissible 60s rollback window for backup restores.
