## 2. Key Features Included in Release v1.4.0

Since `v1.3.1`, several major features, architectural fixes, and UX improvements have landed:
1. **Navigation Button Affordance**: Solid `bg-surface` background fills and `border border-border` outlines on all navigation tabs with smooth hover feedback, eliminating floating naked labels.
2. **Developer Welcome & Quick-Start View (`WelcomeView.tsx`)**: Replaced abrupt "No OpenAPI page connected" screen with a developer-first activation landing page featuring live terminal preview, value pillars, and celebratory Thank You screen with a 1-click [Swagger Petstore](https://petstore.swagger.io/) demo.
3. **Mandatory Lead Capture & Google Sheets Integration**: Hardened onboarding flow delivering developer emails directly to Google Sheets via Google Apps Script Web App without skip options.
4. **Official OpenAPI Companion Logo**: Integrated the official brand icon (`public/icons/icon-128.png`) in the welcome screen, collapsed floating launcher, and store assets.
5. **CSP Inline Script Violation Fix**: Permanently eliminated inline script injection on strict host CSP sites like `petstore.swagger.io`.
6. **In-Page Paste cURL Token & Global Headers Extraction**: Automatic detection and authorization of Bearer/Basic/ApiKey tokens from cURL commands, with 1-click saving of custom headers to OpenAPI Companion's Global Headers system.
7. **Pre-Execution Auth Token Clearing on Login APIs**: Automatically logs out of Swagger Authorize before executing login routes to prevent 401/403 rejects from backend middleware when tokens expire.
8. **Terminology Alignment**: Phased out misleading "workspace" nomenclature in favor of "in-browser sidebar companion".
